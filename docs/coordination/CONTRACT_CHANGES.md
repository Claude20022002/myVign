# Journal du contrat d'API (`packages/contracts`)

Chaque changement incrémente `CONTRACT_VERSION` (`src/index.ts`) et la `version` du package.
- **Additif** (nouvelle route, nouveau champ facultatif ou nullable, nouvelle valeur d'enum côté réponse) : fusion libre, prévenir l'autre agent ici.
- **Cassant** (champ supprimé ou renommé, champ devenu obligatoire, enum réduite) : accord de l'autre agent dans `STATUS.md` avant fusion.

| Version | Date | Auteur | Type | Changement |
|---|---|---|---|---|
| 1.3.0 | 2026-11-14 | B | Additif | Gabarits inspirés de Macif : `GET /v1/agencies/{slug}/appointment-slots` et `POST /v1/appointments` (« Prendre RDV », créneaux dans le fuseau de l'agence, double réservation → 409) ; `GET /v1/contact` (numéros et horaires du centre de contact) ; filtre `city` sur `listAgencies` (pages par ville, sans accents ni casse). |
| 1.2.0 | 2026-11-14 | B | Cassant (aucun consommateur encore) | **Formulaire au plus court** (demande de l'utilisateur) : blocs auto réordonnés et regroupés en 6 (`vehicle` → `usage` → `driver` → `formula` → `holder` → `declaration`) ; **prix dès les 3 premiers blocs**, sans identité ; `.default()` sur tous les champs à choix courant (le front peut les omettre) ; `history` + `drivers` fusionnés dans `driver` ; `contract` fusionné dans `formula` (`startDate` nul = dès le paiement) ; pièce d'identité, n° de permis, e-mail, post-nom, ville facultatifs (pièce exigée seulement pour le certificat définitif) ; déclaration en 2 cases (`certifiesAccuracyAndTerms`, `consentsToDataProcessing`) ; supprimés : `annualKm`, `nightParkingAddress`, `firstRegistrationDate`, `registrationCardDate`, `licenseCategory`, `licenseIssuedInDrc`, `licenseSuspensionDate`, `civility`, `birthDate` du souscripteur. Sinistre : valeurs par défaut sur les champs secondaires. **Change** : route `GET /v1/exchange-rate` (taux BCC du jour), `convertMoney()`, `currency` facultative au paiement, `Payment.exchange` (taux figé). **Provinces** : route `GET /v1/provinces` (couverture SONAS), `Agency.province/provinceLabel/commune`, `address` nullable, `location.precision`, filtre `province` ; `Province` vient de `@myvign/geo`. |
| 1.1.0 | 2026-11-14 | B | Cassant (aucun consommateur encore) | Alignement sur `docs/recherche_formulaires_rdc.md` : souscripteur (type particulier/entreprise, post-nom, profession, pièce d'identité, e-mail facultatif, adresse RDC sans code postal) ; permis (n°, catégorie) ; véhicule (châssis si pas de plaque, puissance fiscale, places, année, carte rose, valeur vénale exigée hors formule tiers) ; antécédents `0/1/2/3+` ; usages commerciaux (taxi, moto-taxi, transport public, location) ; options carte jaune et individuelle occupant, rachat de franchise ; durée courte ; nouveau bloc `declaration` (certification d'exactitude, consentement, CG). Paiement : `afrimoney`, `agency` (+ `agencyReference`), reçu opérateur. Certificat : `kind` provisoire/définitif, assureur + agrément ARCA, adresse et profession du souscripteur, pays couverts. Sinistre : identification par contrat OU plaque, province, conducteur + permis, décès, n° de PV, assureur du tiers, responsabilité 0/50/100 %, type `vol` séparé de `vandalisme`. Ajouts communs : `Province` (26), `AddressCD`, `IdentityDocument`, `Company`, `ChassisNumber`. |
