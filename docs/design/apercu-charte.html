Les couleurs du logo, dosées pour ne pas fatiguer

Le bleu porte l'identité, le jaune désigne l'action à faire, le rouge est gardé pour l'urgence. Tout le reste est neutre, pour que l'œil se pose d'abord sur ce qui compte.

Palette

Contrastes mesurés selon le WCAG 2.2. Le bleu et le jaune du logo ne servent jamais de couleur de texte : leurs versions foncées prennent le relais.
